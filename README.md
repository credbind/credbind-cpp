# CredBind C++ verifier

This repository will contain the independently designed, offline C++17
`credbind-ssh-authorized-keys` verifier for CredBind SSH v1.

The initial checkpoint only establishes the repository and pins the immutable
`v1.0.0-rc.1` language-neutral conformance input. It contains no verifier
implementation and makes no conformance, security, packaging or platform
claim. The implementation order and acceptance requirements are owned by the
[C++ rewrite plan](https://github.com/credbind/planning/blob/main/rewrite/languages/cpp.md).
